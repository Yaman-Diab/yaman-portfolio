# Screenshots

Each project shows three phone screens. Put the pictures here, one folder per project:

```
engleazia/1.png   engleazia/2.png   engleazia/3.png
wafir/1.png       wafir/2.png       wafir/3.png
maan/1.png        maan/2.png        maan/3.png
mishwar/1.png     mishwar/2.png     mishwar/3.png
```

- PNG, JPG, WebP and AVIF all work. Use the phone's own screenshot, full size.
- Portrait screenshots fit best (about 9:19.5, like 1080 × 2340).
- The build makes small, compressed copies, so large files are fine.
- A missing file shows an empty phone frame with the screen's name.

The name and description of each screen are in `src/data/content/en.ts` and `ar.ts`, under `screens`. Change them there if the screenshots you add show different screens.
